# Python File Organizer Script

Hi, I'm Mozahid. This is a simple automation tool I wrote to solve a daily problem: a messy desktop!

## Why I made this
I am currently preparing for my BSc in Computer Science and applying for the Türkiye Bursları scholarship. While studying, my "Downloads" folder always gets full of random PDFs, images, and videos.

Instead of organizing them manually every day, I decided to write a Python script to do it for me. It was a great way to practice working with Python's `os` and `shutil` libraries.

## How it works
The script checks a specific folder (like Downloads). It looks at the file extension (e.g., `.jpg`, `.pdf`) and moves the file into a matching folder (Images, Documents, etc.).

## How to use it
1. Download the `organizer.py` file.
2. Open it in any code editor (like PyCharm or VS Code).
3. Change the `target_dir` path to the folder you want to organize.
4. Run the script.

## Future Plans
I plan to add a feature that automatically unzips `.zip` files in the future.
